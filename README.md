# Exercícios de Java — Banco de Dados

Aqui estão atividades da disciplina Programação em Java — Banco de Dados, organizadas por assunto para facilitar os estudos e a consulta.

- [Estruturas de repetição](src/ProgramacaoJavaBancoDados/EstruturaRepeticao): exercícios com laços e três desafios adicionais.
- [Classes e métodos](src/ProgramacaoJavaBancoDados/ClassesMetodos): classes de domínio e 50 programas para praticar orientação a objetos.
- [Arrays](https://github.com/Elton-Silva607/aprendendo-java-array): lista de 50 exercícios em um repositório próprio, sem duplicar os arquivos aqui.

## Como executar

Abra o repositório no IntelliJ IDEA, marque `src` como pasta de código-fonte se necessário e execute a classe desejada. Algumas atividades pedem dados pelo console. Em ClassesMetodos, os arquivos de `dominio` são usados pelos programas em `test`.

Este repositório faz parte dos meus estudos e pode evoluir com novas práticas e revisões.
